# Product Requirements Document (PRD)

## 产品概述

将闲置的初代 iPad 改造成电子相框，自动轮播 NAS 上的照片，同时显示实时时钟和天气信息。

## 用户场景

老 iPad 固定摆放做桌面相框，自动轮播本地相册、屏幕常驻时间 + 天气。

## 功能清单

### ✅ 核心功能（已实现）

| 功能 | 说明 |
|------|------|
| 全屏自适应 | 适配初代 iPad 1024×768 分辨率，自动横屏 |
| 照片轮播 | 从 NAS 读取照片，自动轮播，支持递归遍历子目录 |
| 手动切换 | 上一张/下一张按钮，手动切换后暂停自动轮播 10 秒 |
| 实时时钟 | 显示年月日、星期、时分秒（设备本地时间） |
| 实时天气 | 通过和风天气 API 显示温度、天气状况、风力 |
| Docker 部署 | 一键部署到群晖 NAS |

### ⭕ 可选迭代（后续版本）

- 自定义相册文件夹选择
- 夜间模式（自动降低亮度）
- 节假日/纪念日壁纸
- 照片过渡动画效果选择

## 非功能需求

| 需求 | 说明 |
|------|------|
| 离线可用 | 断网时仍可正常轮播图片 + 走本地时钟 |
| 低内存占用 | 适配老旧 iPad 硬件（256MB RAM） |
| 图片格式 | 支持 jpg/png |
| 天气 API | 和风天气免费 API（每天 1000 次调用） |
| 缓存策略 | 照片列表缓存 5 分钟，天气缓存 30 分钟 |

## 输入输出规则

| 项目 | 规则 |
|------|------|
| 图片输入 | NAS 目录中的 jpg/png 文件，支持子目录 |
| 天气输入 | 和风天气 API v3 (now) |
| 时钟输出 | 设备本地时间，每秒刷新 |
| 天气输出 | 温度、天气状况文字、风力，每 30 分钟刷新 |
